# personality_sim

Слой личности NPC. Числовая модель + рендер в системный промпт.

    from personality_sim import Person, Interlocutor, Desire, Habit, Abilities, SelfConcept

## Пайплайн

    Person(...)            # 1. инициализация
      .assemble(who)       # 2. сборка снимка из подсистем  -> PersonaSnapshot
      .system_prompt(who)  # 3. рендер промпта              -> PersonaPrompt

`system_prompt()` сам вызывает `assemble()`. Напрямую `assemble()` нужен, только
если снимок идёт не в промпт, а в другую подсистему.

## Промпт

    pr = person.system_prompt(Interlocutor("Аэн", female=True), scene="караулка, ночь")

    pr.stable      # личность. НЕ меняется -> кешируется провайдером
    pr.volatile    # состояние на этот тик. Пересобирается каждый вызов
    pr.as_text()   # обе части одной строкой
    pr.as_messages()  # list[dict] с cache_control на stable

В API отдавать `as_messages()`: стабильный префикс кешируется, платишь только
за летучую часть. Намерение, выбранное симуляцией, кладётся в user-сообщение,
не в системный промпт.

## Обновление состояния

Событие ударило по персонажу:

    person.state.apply(person.temperament,
                       dp=-0.6,   # удовольствие
                       da=+0.7,   # возбуждение
                       dd=-0.4,   # доминирование
                       cost=0.5)  # сколько сил сожрало

Сила удара умножается на `reactivity` темперамента: флегматик почти не заметит,
холерик взорвётся. Ничего домножать руками не надо.

Ход времени — раз в игровой тик:

    person.state.tick(person.temperament, dt=1.0)

`tick()` тянет настроение обратно к базовой линии (скорость задаёт `inertia`),
восстанавливает силы, медленно растит потребности и гасит вес старых
воспоминаний. Без вызова `tick()` персонаж застынет в текущем настроении навсегда.

Потребности и отношения правятся напрямую:

    person.state.needs["order"] = 0.8       # 0..1, дефицит
    person.state.attitudes["Аэн"] = -0.5    # -1..1

## Память

Записать:

    person.state.remember("она провела чужаков через твой пост ночью",
                          who="Аэн", valence=-0.8, weight=1.0)

`valence` — как он это пережил (-1..1), `weight` — значимость, затухает в `tick()`.
Эпизоды с весом ниже 0.05 удаляются сами.

Прочитать:

    person.state.recent(3)              # три самых ярких воспоминания вообще
    person.state.recent(3, who="Аэн")   # три самых ярких, связанных с ней
    person.state.attitude("Аэн")        # отношение, 0.0 если незнакомы

В промпт попадают только воспоминания о текущем собеседнике, и только три
самых сильных (вес * модуль валентности). Остальное не грузится — это экономия
контекста, а не потеря данных: полная память остаётся в `state.episodes`.

## Сохранение

    blob = json.dumps(person.to_dict(), ensure_ascii=False)   # ~2 КБ на персонажа
    person = Person.from_dict(json.loads(blob))

Слепок включает и личность, и память. Roundtrip даёт побайтово тот же промпт.

## Изменение личности

Настроение, нужды и память меняются свободно — промпт это подхватит сам.
Но если поменялось что-то из **стабильной** части (выучил навык, сменилась цель,
сдвинулся архетип), кеш надо сбросить:

    person.abilities.skills["дознание"] = 0.8
    person.touch()

Без `touch()` останется старый стабильный префикс.

## Выбор действия

    person.score(satisfies={"order": 1.0, "control": 0.7}, risk=0.3,
                 requires={"меч": 0.5})

Возвращает полезность; `-inf`, если не хватает навыка из `requires`.
Решение принимает симуляция, модель только озвучивает выбранное намерение.
