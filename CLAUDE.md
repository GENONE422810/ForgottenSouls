# Forgotten Souls

RPG-песочница, где игрок — ослабевшая душа бога. Мир ведут три ИИ-роли,
механика остаётся детерминированной.

## Где что

- `Docs/` — концепт, архитектура, модель данных, механики. **Читать до кода.**
  Новому агенту: `Docs/README.md` задаёт порядок чтения.
- `ROADMAP.md` — этапы разработки и их порядок
- `Person/` — слой личности NPC. Работает, покрыт прогоном
- `AI/` — клиент модели, сцена, эмпат. Работает на заглушке
- `World/` — хранилище мира: записи-словари, обратный индекс, обход
- `*.gd` в корне — легаси генерации мира. **Не трогать**, пока не дойдёт очередь

## Состояние

| | |
|---|---|
| Готово | `Person` (личность, память, сериализация), `Empath` (отыгрыш NPC, сольный и пакетный режим), `World.Store` (хранилище, индекс, обход) |
| Не начато | `TePa`, `RoHa`, `Narrator`, `Judje`, бой, симуляция регионов |
| Ни разу не проверялось на живой модели | всё |

## Как запускать

    python3 -m AI.dryrun      # весь цикл на заглушке, без токенов
    python3 -m Person.demo    # разбор одной личности
    python3 -m World.demo     # хранилище: индекс, обход, roundtrip
    python3 -m World.view_demo # обёртки над записями
    python3 main.py           # живой диалог, нужен AI/.env с ключом

`AI/dryrun.py` — основной способ проверки. Он гоняет сцену на `StubLLM`
и печатает, что ушло бы в модель. Любая новая роль должна уметь
прогоняться так же, без сети.

## Договорённости

- Комментарии и документация — по-русски, код и имена — по-английски
- Логика на Python, Godot — только UI и только на Этапе 4
- Границу «ИИ ↔ механика» держит `TePa`. ИИ не имитирует механику,
  а вызывает её через `[служебные:вызовы]`
- Вывод модели всегда валидируется по схеме. Строки никуда не передаются
  напрямую
- Никаких франшизных имён в данных, промптах и примерах — см.
  `Docs/01-concept.md`, раздел про права
